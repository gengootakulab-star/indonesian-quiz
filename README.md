# インドネシア語 単語クイズ

場面ごとの例文でインドネシア語の単語を覚えて、覚えたい単語をストックし、クイズで復習できるツールです。

**▶ ツールを使う:** https://gengootakulab-star.github.io/indonesian-quiz/

「言語オタクの多言語学習ラボ」で公開しているツールの一つです。
サイト: https://gengootakulab-star.github.io/

## できること

- **カテゴリーから学ぶ:** 色、数、食べ物、飲み物、果物、家族・人、曜日、時間、場所、動詞、形容詞の11カテゴリー
- **場面のフレーズから学ぶ:** あいさつ、自己紹介、食事、買い物、移動、困ったときの6場面
- **ストック:** 覚えたい単語を選んでためておけます
- **クイズ:** ストックした単語で、日本語 → インドネシア語、インドネシア語 → 日本語 のクイズができます

## 使い方

1. カテゴリーか場面を選んで、単語やフレーズを読みます
2. 覚えたい単語をストックに入れます
3. 「ストックからクイズ」で、出題の向き(日→イ/イ→日)を選んで解きます

## ストックと成績の保存

ストックした単語とクイズの成績は、使っているブラウザの中にだけ保存されます。別の端末には引き継がれず、ブラウザのデータを消すと消えます。

## 単語と例文について

- 収録している単語(171語)は、[Wiktionary](https://en.wiktionary.org/) と照らし合わせて確認・修正しています
- 例文(フレーズ)は、まだインドネシア語のネイティブの方の確認を受けていません。不自然な表現が含まれている可能性があります

## ご注意

- 運営者はインドネシア語の専門家ではなく、個人が趣味で作っている学習用のツールです
- 正確さが必要なときは、辞書や先生など、ほかの情報源もあわせて確認してください
